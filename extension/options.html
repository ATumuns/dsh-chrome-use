DSH-Chrome-Use

这个扩展到 DeepSeek Harness 的本地桥接拨出，把当前浏览器交给 DSH 操作。 走 CDP（chrome.debugger），因此点击、输入是可信事件，页面无需注入常驻脚本。

配对

使用步骤

  1. 在 DSH 里确认扩展已配对：调用 chrome_use_status，connected: true 即通。
  2. 让 DSH 打开页面：chrome_use_open_tab 或直接 chrome_use_navigate。
  3. 取快照看页面结构：chrome_use_snapshot 返回可交互元素的 ref（如 e12）与文本大纲。
  4. 用 ref 操作：chrome_use_click / chrome_use_type / chrome_use_press，无需坐标。
  5. 排错时看 chrome_use_console 与 chrome_use_network，截图用 chrome_use_screenshot。
